Why no framework?

For a page this size, the platform is enough. Less code means faster loads and fewer moving parts.

Does it work on phones?

Yes — fluid type and grid layouts adapt from 320 px up, with no horizontal scrolling.

Is it accessible?

Every control is reachable by keyboard, labelled for screen readers, and motion respects your OS setting.
